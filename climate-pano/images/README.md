# Panorama images

Add two **equirectangular** 360° photos of the **same location** (2:1 aspect ratio, e.g. 4096×2048):

| File | View |
|------|------|
| `present.jpg` | Today / without climate effects |
| `future.jpg` | Same spot with climate change effects |

Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp` — update paths in `../app.js` if you use different names.
