Expense supplierId migration

The expense app links expenses to suppliers by supplierId only. This tool assigns supplierId (and refreshes denormalized name/TIN/address) for expenses that are missing it. Run once per environment, then use the normal app.

← Admin · Mobile app

Order of operations
  1. Initialize Firebase (only needed for Firestore load/apply).
  2. Load from Firestore (source of truth for multi-device) or Load from localStorage (this browser only).
  3. For each ambiguous supplier name, pick the canonical supplier row in the dropdowns.
  4. Apply to Firestore or Apply to localStorage (writes only expenses whose supplierId changed).
  5. Open the expense app and sync/fetch so all devices converge.
